# Seed dữ liệu kiểm thử

Chạy `Seed_2000.sql` bằng SQL Server Management Studio trên database EnglishCenter.

Script không xóa dữ liệu hiện có và có thể chạy lại an toàn. Kết quả tối thiểu gồm 2.000 Users, 2.000 Students, 2.000 Enrollments và 1.000 Invoices mẫu. Tài khoản seed dùng mật khẩu `password`.
